Privacy Policy

Last updated: 24 October 2026

Peptide Ape Uploader is a private tool used only by the owner of the Peptide Ape YouTube channel to upload that channel's own videos. It is not offered to anyone else.

What it accesses

With the channel owner's permission, the tool uses the YouTube Data API to upload videos, set their titles, descriptions, tags, privacy and thumbnails, on the owner's own channel. It does not read, collect or store data about viewers or any other YouTube users.

How credentials are stored

The authorisation token is stored as an encrypted secret in the owner's private GitHub repository and is used only to run uploads. It is not shared with anyone.

Sharing

No data is sold, shared or used for advertising.

YouTube and Google

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be removed at any time from Google account permissions.

Contact

Questions can be sent through the Peptide Ape YouTube channel.
